# 雷达SDH100上云协议

## **1\. 约定**

|Topic|用途|
|---|---|
|`thing/product/{SDH100设备SN}/services`|云→设备 查询/设置|
|`thing/product/{SDH100设备SN}/services_reply`|设备/网关应答|
|`thing/product/{SDH100设备SN}/osd`|设备主动上报|

- **result**（天盾）：\`0\`成功 \`1\`失败 \`2\`超时 \`3\`离线 \`4\`状态冲突 \`5\`重启中

## 公共 CloudMessage 定义

SDH100 协议作为 3 份上云协议文档（Spotter/Spotter Pro、SDH100、Tracer）之一，统一使用以下统一使用以下 `CloudMessage` 作为外层信封。各协议只需定义业务 payload message，通过 `google.protobuf.Any` 承载在 `data` 字段中，`type_url` 标识具体 payload 类型。

所有协议 `import "cloud_message.proto"`，共用同一外层信封。

```protobuf
syntax = "proto3";
import "google/protobuf/any.proto";

package cloud;

// 外层信封，3 份上云协议文档全部用这一个
message CloudMessage {
  string tid       = 1;  // 事务 UUID
  string bid       = 2;  // 业务 UUID
  int64  timestamp = 3;  // 毫秒时间戳
  string gateway   = 4;  // 设备 SN
  string method    = 5;  // "spotter_fusion_targets" / "sdh100_xxx" / "stf200_xxx" / ...
  google.protobuf.Any data = 6;  // 业务载荷，type_url 标识具体 payload 类型
}
```

**字段顺序**（元数据 → 路由 → 载荷）：

- 元数据：`tid`, `bid`, `timestamp`

- 路由：`gateway`, `method`

- 载荷：`data` \(Any\)

**请求/应答区分**：不加 direction / ack 字段，靠 Topic 区分——`/services` = 请求，`/services_reply` = 应答。请求与应答共享同一 method 值。

**data 内部平铺**：payload 字段直接平铺在 data 内部，不嵌套 `{request}` / `{response}` 一层。

**JSON 编码**：`data` 字段使用 protobuf Any 的标准 JSON 编码，以 `@type` 标识具体类型：

```json
{
  "tid": "65717bf1-aee7-4abb-8ea3-9b1908548d74",
  "bid": "65717bf1-aee7-4abb-8ea3-789854512232",
  "timestamp": 1667220873846,
  "gateway": "SDH100_SN_001",
  "method": "sdh100_set_config",
  "data": {
    "@type": "type.googleapis.com/cloud.Sdh100SetConfigReqData",
    "sn": "SDH100_SN_001",
    "timestamp": 1667220873800
  }
}
```

**Any 路线 vs Struct 路线 — 关键 Trade\-off**

- ✅ **类型安全**：`unpack(XxxData.class)` 编译期校验 payload 类型

- ✅ **code\-gen 强类型**：所有语言 SDK 一行 unpack 拿到强类型字段

- ✅ **跨语言 SDK 自动**：protobuf 工具链覆盖 C\+\+/Java/Go/Python

- ✅ **wire 编码零损耗**：payload 是原 message 编码

- ✅ **调试可读**：`.toString()` 是结构化 protobuf text format

- ⚠️ **加 method 需改外层 proto 重生成代码**（可控、低频）

- ⚠️ **type\_url 是字符串约定**，写错类型 unpack 失败靠 runtime 报错

**⚠️ Wire Format 大变更**
CloudMessage 完全替代原外层 message（如 `SDH100` 各方法原 `XxxRequest` / `XxxReply`），是 wire\-format 大变更。所有现存 device/cloud 解析代码全部失效，需同步改造。

## **2\. 协议一览**

|CMD|method|Topic|说明|
|---|---|---|---|
|0xB0|`sdh100_set_config`|services / services\_reply|统一设置|
|0xB1|`sdh100_get_config`|services / services\_reply|统一查询|
|0x20|`device_heart`|`thing/product/{SDH100设备SN}/osd`|心跳/状态上报|
|0xB5|`sdh100_set_mask_v2`|services / services\_reply|雷达 Mask V2 设置|
|0xB6|`sdh100_get_mask_v2`|services / services\_reply|雷达 Mask V2 获取|

|0x0105|`sdh100_city_learning_status`|services / services\_reply|获取学习信息|
|`0x1101`|`device_progress`|thing/product/\{SDH100设备SN\}/osd|学习进度|
|`0x1102`|`device_progress`|thing/product/\{SDH100设备SN\}/osd|学习完成/失败上报|

## Method → Payload 字段映射表

SDH100 协议所有 method 对应的业务 payload type。请求/应答共享同一 method 值，靠 Topic 区分方向（`/services` = 请求，`/services_reply` = 应答，`/osd` = 上报）。

|method|请求 payload|应答 payload|Topic|说明|
|---|---|---|---|---|
|`sdh100_city_learning_enable`|Sdh100CityLearningEnableReqData |`Sdh100CityLearningEnableReplyData `<br>|`/services & /services_reply`|城市模式启停学习|
|`device_progress`|`—`|`Sdh100CityModeLearningResult `|`thing/product/{SDH100设备SN}/osd`|学习完成/失败上报|
|`device_progress`|`—`|Sdh100CityModeLearningResult |`thing/product/{SDH100设备SN}/osd`|学习进度|
|`sdh100_city_learning_status`|`Sdh100CityLearningStatusReqData`|`Sdh100CityLearningStatusReplyData`|`/services & /services_reply`|城市模式 — 获取学习信息|
|`sdh100_get_config`|Sdh100GetConfigReqData|`Sdh100GetConfigReplyData`|`/services & /services_reply`|统一查询雷达配置参数|
|`sdh100_get_mask_v2`|`Sdh100GetMaskV2ReqData`|`Sdh100GetMaskV2ReplyData`|`/services & /services_reply`|雷达 Mask V2 获取|
|`device_heart`<br>|`—`|`Sdh100State`|`thing/product/{SDH100设备SN}/osd`|雷达状态上报|
|**`device_mark`**|`—`|`Sdh100GetMaskZoneRsp`|`thing/product/{SDH100设备SN}/state`|雷达mask上报|
|`sdh100_set_config`|`Sdh100SetConfigReqData`|`Sdh100SetConfigReplyData`|`/services & /services_reply`|统一设置雷达配置参数|
|`sdh100_set_mask_v2`|Sdh100SetMaskV2ReqData|`Sdh100SetMaskV2ReplyData `|`/services & /services_reply`|雷达 Mask V2 设置|

### **Protobuf**

```protobuf
// Topic: thing/product/{SDH100设备SN}/services
// method: sdh100_set_config
// 对应设备协议: 0xB0 / Sdh100C2Config
// 外层使用 CloudMessage（见文档开头公共定义）
// 请求 data payload 类型: cloud.Sdh100SetConfigReqData


message Sdh100SetConfigReqData {
  string sn = 1;            // SDH100 SN（上云路由）
  Sdh100C2Config config = 2; // 设备协议字段，按需填写
}

// 对应设备 Sdh100C2Config（msgid 0xB0 请求 / 0xB1 应答复用）
message Sdh100C2Config {
  optional string sn = 1;
  optional string version = 2;
  optional double longitude = 3;        // 经度
  optional double latitude = 4;         // 纬度
  optional double altitude = 5;         // 高度
  optional double heading = 6;          // 方位角
  optional double pitching = 7;         // 俯仰角
  optional double rolling = 8;          // 横滚角
  optional float ele_scan_center = 9;     // 俯仰扫描中心位置(°)
  optional float ele_scan_scope = 10;     // 俯仰扫描范围(°)
  optional float azi_scan_center = 11;    // 方位扫描中心位置(°)
  optional float azi_scan_scope = 12;     // 方位扫描范围(°)
  optional uint32 radar_scan_radius = 13; // 扫描范围(m)，默认 1500
  optional uint32 filter_level = 14;     // 滤波等级
  optional uint32 electricity = 15;     // 电池电量百分比
  optional uint32 status = 16;          // 雷达状态位域，见设备协议
  optional uint32 sys_status = 17;       // 系统状态
  optional uint32 f_channel = 18;        // 频分通道 1 2 3 4
  optional uint32 t_channel = 19;        // 时分通道
  // 1系统复位 2恢复出厂 3设置状态上报周期 4设置目标上报周期
  // 5自动标定姿态 6使用实时姿态 7开始侦测 8结束侦测
  optional uint32 mode = 20;
  optional uint32 clutter_mode = 21;     // 0晴天 1雨天
  optional uint32 otm_mode = 22;         // 0 disable 1 enable
  optional uint32 otm_time = 23;         // default 100ms
  optional float imu_height = 24;
  optional uint32 enable_city_mode = 25;  // 城市模式生效 0-off 1-on
  optional uint32 micro_doppler_flag = 26;// 微多普勒识别 0-off 1-on
}

// Topic: thing/product/{SDH100设备SN}/services_reply
// method: sdh100_set_config
// 对应设备协议: 0xB0 / Sdh100C2SetConfigRsp
// 外层使用 CloudMessage（见文档开头公共定义）
// 应答 data payload 类型: cloud.Sdh100SetConfigReplyData


message Sdh100SetConfigReplyData {
  int32 result = 1; //天盾统一响应
  Sdh100C2SetConfigRsp output = 2;
}

message Sdh100C2ErrCode {
  string name = 1;
  uint32 code = 2;
}

message Sdh100C2SetConfigRsp {
  uint32 status = 1;                // 0成功 1失败
  repeated Sdh100C2ErrCode err_code = 2;
}
```
